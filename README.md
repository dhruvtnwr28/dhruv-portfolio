# ⚡ Dhruv Tanwar — Next-Gen 3D Portfolio

> An avant-garde, award-winning interactive portfolio experience featuring real-time 3D graphics, fluid physics, kinetic typography, and interactive spatial soundscapes.

## 🚀 Vision & Architecture
- **Framework:** Next.js 15 / React 19
- **3D Engine:** Three.js / React Three Fiber / @react-three/drei
- **Custom Shaders:** GLSL (Fluid simulations, chromatic aberration, holographic bloom)
- **Animation & Physics:** GSAP (ScrollTrigger), Lenis Smooth Scroll, Framer Motion
- **Styling:** Tailwind CSS + Custom Cybernetic Design System
